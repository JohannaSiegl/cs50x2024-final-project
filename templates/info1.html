WHAT IS THE BINARY SYSTEM

The binary system is a numeral system that uses only two different symbols to represent numbers. The decimal system, which we use most of the time, uses ten different symbols, 0 through 9. The binary system uses only the symbols 0 and 1. The place value of each digit is the power of two of the corresponding place. The digit with the highest value is on the left and the digit with the lowest value is on the right. The value of a binary number is the sum of the powers of two represented by each digit with the symbol 1.

For example, the binary number 1011 can be written as 1*23 + 0*22 + 1*21 + 1*20, which is the decimal number 11.
